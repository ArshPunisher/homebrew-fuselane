# Homebrew tap for Fuselane

[Fuselane](https://github.com/ArshPunisher/fuselane) downloads one file over every network you have at once (Wi-Fi, Ethernet, a USB-tethered phone) and fuses the parts into one file.

```sh
brew install --cask arshpunisher/fuselane/fuselane
```

The cask is updated from each published release with its SHA-256. Fuselane is open source and ad-hoc signed (not notarized), so the cask clears the quarantine flag after installing, the same thing "Open Anyway" does.
